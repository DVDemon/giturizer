## Вехи (обзор)

| Веха | Граница | Результат |
|------|---------|-----------|
| **M1** | конец P1 | API + БД: проекты и запуски, постановка задачи в очередь |
| **M2** | конец P2 | Анализ работает через API (без UI): клон → анализаторы → нормализованные данные в БД |
| **M3** | конец P5 | Полный артефакт: единый JSON (технологии/API/deployment) + C4 |
| **M4** | конец P6 | UI-демо: URL → визуализация архитектуры |
| **M5** | конец P7 | Релиз v1.0: e2e, безопасность, документация |

## Критический путь

`P1 (ядро) → P2 (пайплайн) → P5 (JSON-отчёт) → P6 (UI) → P7 (релиз)`

## Блокирующие развилки

Все архитектурные решения приняты (см. [реестр ADR](../adr/README.md)):

- [ADR-0012](../adr/0012-gitlab-access.md) — access token;
- [ADR-0010](../adr/0010-graph-storage.md) — Neo4j;
- [ADR-0011](../adr/0011-worker-analyzer-interaction.md) — очередь + общий volume (без docker.sock);
- [ADR-0021](../adr/0021-json-report.md) — единый JSON-отчёт.
- [ADR-0009](../adr/0009-structurizr-output.md) — прежний Structurizr-вывод (заменён).

Плановых блокеров нет — можно стартовать **P0**.
