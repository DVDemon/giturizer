# ADR-0008: Одиночный пользователь / внутренний режим

- **Статус:** Принято
- **Дата:** 2026-11-23

## Контекст

Нужно решить, требуется ли аутентификация и разделение проектов по пользователям в v1.

## Решение

В v1 — **одиночный пользователь / внутренний режим**: без сложной авторизации (опционально простой
статический токен), все проекты в общем пространстве. Мультиарендность откладывается на v2.

## Альтернативы

- **Мультиарендность + GitLab OAuth** — проекты привязаны к пользователям/группам; нужны OAuth-флоу,
  RBAC, модели владения.
- **Basic auth / LDAP** — простая корпоративная авторизация.

## Последствия

- Быстрее v1, проще docker-compose (без identity-компонента).
- Позже добавить auth-слой поверх (например, `api` получает middleware авторизации без смены БД).
