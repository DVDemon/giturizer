# ADR-0003: Собственный веб-вьюер (Cytoscape.js + Mermaid + Swagger UI)

- **Статус:** Принято
- **Дата:** 2026-11-23

## Контекст

Нужно показывать архитектуру в вебе: C4-диаграммы, граф зависимостей, спецификации API. Structurizr
предлагает официальный рендерер (Structurizr Lite), но он ограничен в интерактивности и не покрывает
одновременно граф зависимостей и API-просмотр.

## Решение

Строить **собственный вьюер** на React/TypeScript:

- **Cytoscape.js** — интерактивный граф зависимостей (drill-down, фильтры, подсветка транзитивных связей).
- **Mermaid** — рендер C4-диаграмм (Context/Container/Component) из внутренней модели.
- **Swagger UI / Redoc** — просмотр извлечённых OpenAPI-спецификаций.

Structurizr при этом остаётся каноническим **форматом вывода** (DSL + JSON) для экспорта и импорта
в сторонние Structurizr-инструменты, но рендер делаем сами.

## Альтернативы

- **Structurizr Lite** — меньше работы, официальный рендер, но слабая интерактивность графа и нет
  единого UX для API/технологий.
- **Оба** — Lite для C4 + свой граф; двойной рендер усложняет UI и деплой.

## Последствия

- Полный контроль над UX и единая точка просмотра (граф + C4 + API + технологии).
- Нужно самим поддерживать маппинг внутренней модели → Mermaid/Cytoscape.
